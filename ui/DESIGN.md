# Doodleworld design
An off-white field notebook with charcoal pen strokes, leaf-green accents and warm yellow annotations. The map is the main experience: soft grid paper, hand-drawn trees, houses, running characters and activity marks. Floating controls frame the canvas; a compact right notebook reveals real simulation state. System serif headings and monospace metadata avoid external fonts. Primary actions are green; focus rings are visible; dialogs scroll and trap keyboard focus. At narrow viewports, notebook panels become overlays and map controls remain reachable.

Genuine captures dated 2026-10-20: SCREENSHOT.png shows route `/` at a 1363 × 936 browser viewport. SCREENSHOT-MOBILE.png shows the same running route in a real 390 × 844 iframe viewport through the development-only `/__qa/mobile` harness, cropped to the iframe bounds. This is responsive-width evidence, not physical-device emulation. The mobile notebook and creator scrolling were inspected. No mockup or fabricated scene is used.
