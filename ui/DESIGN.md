# Doodleworld design
An off-white field notebook, charcoal strokes, leaf-green accents and warm yellow annotations preserve the original visual language. The 2D scene gains procedural drawings, varied building silhouettes, resource patches, circle boundaries, weather and night tint. An orthographic paper globe uses the same terrain sampler and state; a logarithmic zoom blend transitions to the detailed map. Globe rotation wraps longitude; clicking or entering a location retains every resident and artifact.

The notebook adds Gallery and Circles pages. Selected doodles reveal real thoughts, anger, food/water, trust and latest ideas. User/model text is always rendered with textContent. Keyboard pan/zoom and five-tab arrow navigation supplement pointer and touch. Mobile notebook is an overlay; the globe landing button stays above the transport controls.

## Settlement interface
The map now contains functional houses, wells, granaries, workshops/towers, real crop plots, resource geography and residents/equipment. Legacy decorative artwork is hidden. Plots show crop-specific growth, maturity, drought and fallow state. Housing labels and project inspection expose actual occupants/capacity. Gear and profession markers distinguish farmers, builders, guards/scholars and supported leaders; sovereigns receive a gold status crown.

The former Gallery tab is Settlement. Inspectors lead with six need bars, the current goal/reason, role, household and supplies. Expandable panels show actual proficiencies, mentors, recent outcomes and contextual action values. Creator randomization uses combinatorial descriptions and varied geometry; manual description choices stay authoritative. Settings separates device/export storage from authenticated cloud checkpoints, including conflicts and offline availability. Preserve original paper/charcoal/leaf-green style, keyboard tabs, touch, scrollable notebook and mobile modal layout.
