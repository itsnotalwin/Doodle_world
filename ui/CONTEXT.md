Old decorative art is neither rendered nor clickable. Source/build share the same simulator; model/user text enters DOM via textContent. Keep keyboard/touch/responsive flows accessible. `responsive-preview.html` is a dev-only 390 × 844 iframe harness. Capture real evidence and update DESIGN.md after visual changes. Verify household counts, projects, goals/learned skills, diverse randomization, export/import and globe/map continuity.

Generated, saved and inherited figures use the same layout; children scale once. Build and dev must embed this module before the view code.
