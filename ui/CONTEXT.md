# Game interface
`index.html` owns controls, sketch creator, map loop and the notebook shell. `world-view.js` owns the same-world globe, environment, artwork rendering, gallery and relationship/group inspection. Build embeds both with the shared simulator. The creator supports keyword-based phenotype previews, random genes and freehand drawings. The notebook exposes affiliation reasons, traits, ancestry, remembered lives and the 95-motif vocabulary. User/model text only enters DOM through textContent. Preserve keyboard and touch interaction; camera transitions must never change world state. `responsive-preview.html` is a development-only narrow iframe harness. Capture genuine screenshots after visual edits and record provenance in DESIGN.md. Verify gallery jumps, circles, globe rotation/landing, migration and responsive dialogs.
