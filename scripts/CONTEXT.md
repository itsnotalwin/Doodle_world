# Scripts
Owns dependency-free development, packaging and artifact verification. Build strips module boundaries from the shared simulation files and embeds them with the page and `world-view.js` into one Worker. Validate checks both Worker ESM and the actual embedded browser program for syntax/unresolved placeholders. Dev serves the same sources on port 4173 with no production identity or secrets. Use the Sites preview supervisor for browser QA. Run build and validation before publishing; generated dist stays untracked.
