# Scripts
Owns dependency-free development, packaging and artifact verification. Build strips module boundaries from the drawing-library, life-systems, world-systems, livelihood, agent-brain and engine modules in dependency order and embeds them with the page and `world-view.js` into one Worker, including the same isolated validator and checkpoint handler server-side. Validate checks both Worker ESM and the actual embedded browser program for syntax/unresolved placeholders. Dev serves the same sources on port 4173 with no production identity or secrets. Use the Sites preview supervisor for browser QA. Run build and validation before publishing; generated dist stays untracked.

Embed `ui/character-layout.js` before view sources in both build and dev, stripping its named exports. `tests/visual-layout.test.js` checks geometry and actual camera/creator source behavior. The remote-only polish draft has not run the Node build or artifact validator; rerun them in a restored workspace before merging/publishing.
