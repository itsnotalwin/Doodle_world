# Tests
Node's test runner covers 55 behaviors across the original engine, growing society and the Worker bridge. `evolution.test.js` covers distinct motif geometry, genes, inheritance, developmental learning, autonomous membership/refusal/exit, voluntary rallying, births, lethal attacks, destruction, upgrades and historical records. Test actual art generation/completion, social effects, needs/resources, groups and arrivals, globe round-trips and original-save migration. Worker tests use an actual in-memory SQLite table through a small D1 adapter to verify atomic quota/cooldown and no retries with mocked upstream calls. `livelihood.test.js` checks skill prerequisites, finite beds/planned housing, crop cycles, material conservation, teaching, private learning, inheritance/care, varied silhouettes, supported leadership and sustained territory occupation. `checkpoints.test.js` checks the new SQL schema, owner isolation, concurrent/stale writes, chunked round trips and poisoned saves using real SQLite. Additional long-run checks exercise two simulated hours and 80 residents. Real Groq testing remains separate and awaits a user-supplied server secret.

`visual-layout.test.js` adds six regressions for common saved/inherited character scale, one child scale, the 80,000-point freehand budget without mutation, silhouette-aware annotations, collision-free crowd labels, camera zoom during selection and description-preview encoding. These Node tests await execution in the restored workspace; isolated JavaScript geometry/camera checks are not a substitute for the full suite or screenshots.
