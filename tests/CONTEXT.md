# Tests
Node's test runner covers 36 behaviors across the original engine, growing society and the Worker bridge. `evolution.test.js` covers distinct motif geometry, genes, inheritance, developmental learning, autonomous membership/refusal/exit, voluntary rallying, births, lethal attacks, destruction, upgrades and historical records. Test actual art generation/completion, social effects, needs/resources, groups and arrivals, globe round-trips and original-save migration. Worker tests use an actual in-memory SQLite table through a small D1 adapter to verify atomic quota/cooldown and no retries with mocked upstream calls. Additional long-run checks exercise two simulated hours and 80 residents. Real Groq testing remains separate and awaits a user-supplied server secret.
