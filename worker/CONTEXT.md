# Worker
Owns HTTP routes and the optional Groq bridge. `index.js` exports an app factory accepting the built page. Compact mood/needs/trust snapshots guide bounded action plans, motif recipes and social intentions; validate enums, character IDs and every optional model field. Never execute model code. Calls require authenticated hosted access, a server secret and an atomic D1 quota reservation. Missing quota storage fails closed. Tests mock transport and verify no retries or secret leakage; the real provider remains untested until a secret is supplied.
