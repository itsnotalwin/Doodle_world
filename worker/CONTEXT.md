# Worker
`index.js` serves the app and optional quota-limited Groq suggestions. `world-store.js` owns GET/PUT /api/world, authenticated owner-scoped D1 checkpoints, bounded streaming reads, full shared-simulator validation, chunk storage and atomic optimistic revisions. Never store secrets or send GitHub tokens to clients. Source is in GitHub; evolving individual state is in checkpoints. Missing identity/storage fails closed for cloud operations; local play/export remains. Build embeds the same validator inside the Worker. Test schema, owner isolation, stale/concurrent writes, chunk round trips and invalid bodies against real SQLite. Real Groq still awaits a server key/model and explicit test.
