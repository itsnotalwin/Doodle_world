# Simulation
`engine.js` owns fixed-step movement/activity, conflict and strict version 4 saves. `world-systems.js` owns terrain, resource nodes, social interactions and globe math; legacy art functions remain only for compatibility. `livelihood.js` owns inventory, learned professions, household capacity, farms, gathering, food/water stores, material costs and functional craft/building variation. `agent-brain.js` owns need-driven goals, outcome episodes, contextual action values, roles, supported leadership and basic territory strategy. `life-systems.js` owns genes, phenotype, ancestry, care/birth/death and voluntary group choices. New skills require practice/study/teaching; age cannot unlock construction. No DOM/network here. See SIMULATION.md and behavioral tests. Modules must embed in dependency order, identically in dev/build. Keep state finite, bounded, serializable and migratable; archived art is hidden, not deleted.
