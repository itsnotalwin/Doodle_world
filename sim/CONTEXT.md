# Simulation
Owns fixed-step movement, skill/action learning and strict saves in `engine.js`; `world-systems.js` owns deterministic terrain, weather, resources, social ties, circles, procedural drawing recipes and globe math. No DOM or network belongs here. Both browser and Node tests run the same functions. Version 1 saves migrate additively to version 2 without losing character drawings or progress. Keep all state finite, bounded and serializable. Test behavior, migration, long-run capacity and projection round-trips. Creative output is generated composition, not neural training.
